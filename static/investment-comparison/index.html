1. インデックス3種と3倍レバ：同じ「株式」でも中身は違う

オルカン：リスク源が最も単純

MSCI ACWIは先進国・新興国の大型/中型株を広くカバーし、世界の投資可能株式市場のおよそ85%を対象。2026年8月末で2,458銘柄。

指数の最大ドローダウン： -58.38%（2007/10-2009/3）。広く分散しても株式なので大暴落はある。

S&P500：米国への集中

オルカンより地域集中が強い。S&P DJIの2026年8月末データでは、過去10年の価格リターン年率は13.48%、年率リスクは15.35%。

日本の円換算・配当込みベンチマークでは2015/6-2025/6の10年間で4.2倍。

FANG+：10銘柄に意図的に集中

NYSE FANG+は成長株10社を均等配分。ICEによれば2014/9/19-2026/6/30の年率総合収益は27.41%。ただし指数開始は2017年で、それ以前はバックテスト。

NISAではiFreeNEXT FANG+インデックスが、つみたて投資枠・成長投資枠の両方に対応。

SPXL：日次+300%であって長期3倍ではない

Direxion自身が「1日を超える期間でベンチマークの累積リターンの3倍を期待すべきではない」と明示。

2026年8月末までの10年NAV年率は29.18%だったが、これは強い上昇相場を含む過去実績。

3倍レバの経路依存を2日で見る

通常指数

100 → 90 → 99

1日目 -10%、2日目 +10% = 累計 -1%

日次3倍

100 → 70 → 91

1日目 -30%、2日目 +30% = 累計 -9%

つまり：方向が最終的に戻っても、上下動が大きいほど3倍ETFは削られやすい。長期保有では「レバレッジ倍率」だけでなく、値動きの順序が結果を左右する。

NISAだけで「かなり攻める」選択肢は存在する

オルカン → S&P500 → FANG+ と、NISA内でも分散度を下げて成長株への集中度を上げられる。一方、ヘッジ目的以外のデリバティブを用いる高レバレッジ型投信等はNISAの対象外。

出典：MSCI, S&P Dow Jones Indices, ICE, Direxion, 大和アセットマネジメント, 三菱UFJアセットマネジメント, 金融庁。

3. 類似する失敗事例：何が「似ている」のか

重要：以下はADIF/AIXが同じ不正を行っている、または破綻すると示すものではない。比較しているのは、海外・非上場・高利回り・運用会社依存・換金が相手方依存という「失敗時の構造」です。
MRI International（米国 / 日本人投資家中心）
SECによると、日本在住者を中心に8億ドル超を集め、「米国の医療売掛債権を割安で買う」と説明。DOJの刑事事件では15億ドル規模のPonzi schemeとされ、1万人超の日本人被害者から10億ドル超を勧誘。裁判資料では、医療債権購入に使われたのは投資資金の2%未満とされた。CEOは2019年に懲役50年。
学び：「具体的な実体資産がある」という説明だけでは、実際の資金使途を保証しない。第三者保管・監査・銀行残高の検証が重要。
Exential Group（ドバイ / FX）
Gulf Newsによると、最低2.5万ドルの口座で年率最大120%をうたい、約7,000人の顧客を集めた。後に約11億ディルハム規模のPonzi schemeとして裁判になり、支払い停止が表面化。
学び：高利回りと「安全な運用」を同時に強調する商品は、収益源・ブローカー口座・監査証跡を独立確認する必要がある。
BlueChip（ドバイ / 2024年に支払い停止）
Khaleej Timesによると、最低1万ドル・18か月ロック・月3%（年36%相当）を提示。2024年3月に支払いが止まり、事務所が空になったと報道。後の報道では警察捜査・関係者の逮捕へ発展。
学び：豪華なオフィス、受賞歴、著名人との露出、長い営業実績の見せ方は、資産の分別管理や換金能力とは別物。
Abraaj（ドバイ / 大手プライベートエクイティ）
SECは2019年、Dubai-basedのAbraaj Investment Managementと創業者を、ヘルスケアファンド資金の流用・企業資金との混同等で提訴。対象は1億ドル超の米国慈善団体等の資金。
学び：「大手」「機関投資家も利用」「著名な実績」があっても、非上場資産では資金の分別・ガバナンス・キャッシュ管理が核心。

4. 何を確認すれば「9%が割に合うか」を判断できるか

1返還義務者

元本・分配金を法的に誰が支払う契約なのか。日本法人、合同会社、パナマ法人、AIXのどれか。

2AIX社債の条件

発行体、クーポン、満期、通貨、担保、優先順位、ISIN/証券識別情報、デフォルト条項。

3資金の実在確認

監査済み財務諸表、カストディ/銀行証明、社債保有残高。関連会社作成資料だけでなく独立第三者の確認。

450%以上の「実際の比率」

50%なのか90%なのかで必要運用利回りが大きく変わる。各期の実績比率と販管費率を見る。

5解約・償還

いつ解約できるか、ゲート/延期条項、手数料、評価方法、支払期限、遅延時の権利。

6ストレス時

AIXの支払いが止まった場合、誰が損失を負担するか。ADIF側に保証・準備金・担保があるか。

比較の読み方

目的確認すべき違い
長期の資産成長オルカン/S&P500は、リスク源が主に株価と為替でシンプル。NISA非課税の効果も大きい。
高成長へ集中FANG+ならNISA内でも集中リスクを取れる。透明な市場価格と換金性を保ったままリスクを上げる選択肢。
さらにレバレッジSPXLはリターン可能性も損失速度も大きい。日次リセットのため長期3倍ではなく、NISA対象外。
市場と違う収益源Dubai Investorに意味があるとすれば、株式と異なる収益源・低相関を、追加の信用/換金/法域リスクに見合う形で提供できる場合。その証明資料が核心。
この比較から言えること：
Dubai Investorの9%は、オルカンやS&P500より「数字が高いから有利」というタイプの商品ではない。むしろ、上場インデックスではあまり背負わない信用・流動性・運営・クロスボーダー構造を追加で取る対価として9%が十分か、という見方が重要。
NISAの非課税メリットも忘れない：同じ税引前リターンでも、NISA対象のオルカン/S&P500/FANG+と、NISA外の商品では手取り比較が変わる。
投資判断は契約書・目論見書等の正式書面と、自身のリスク許容度を基に行うこと。
